# Signature publique — à la demande du propriétaire

Ce dossier contient le keystore de signature `nemapibridge-release.p12`, l’alias `nemapibridge` et le mot de passe dans `password.txt`. La clé étant publiée dans un dépôt public, elle doit être considérée comme compromise : n’importe qui peut signer un APK avec cette identité. Passer le dépôt en privé plus tard ne supprime pas les copies existantes. Ne pas réutiliser cette clé pour d’autres produits.

Une nouvelle clé privée exigerait de désinstaller les versions actuelles avant de les remplacer, sauf mise en place préalable d’un mécanisme de rotation compatible.
